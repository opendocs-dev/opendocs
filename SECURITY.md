# Security Policy

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/opendocs-dev/opendocs/security/advisories/new>).

Include the affected version, steps to reproduce, and impact. We aim to reply within 7 days.

## Supported versions

OpenDocs is pre-alpha. Only the latest release receives fixes.
